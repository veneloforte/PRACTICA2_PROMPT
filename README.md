

## Estructura

- data/raw/: archivos originales o crudos
- data/processed/: datos limpios, transformados y exportados
- docs/: documentación y guías
- notebooks/: experimentos, análisis exploratorio y prototipos
- src/: scripts y utilidades del proyecto
- .env.example: plantilla de variables de entorno
- requirements.txt: dependencias del proyecto

## Inicio rápido

1. Copia el archivo .env.example a .env y ajusta las rutas si hace falta.
2. Coloca tus archivos en data/raw/.
3. Ejecuta el proyecto desde la carpeta raíz:

   python src/main.py

4. Crea notebooks en notebooks/ y guarda resultados en data/processed/.

## Objetivo

Usar este espacio como proyecto independiente para pruebas, análisis y resultados con otros datos.
